### Hi, I'm Nathanael

I run **[Mirae Studio](https://miraestudio.id/?utm_source=github&utm_medium=profile)**, a design and development studio in Indonesia. We build websites for brands, publishers, schools, clinics and event organizers, with past clients in Indonesia and Singapore. The same people design and code each site, in English or Bahasa Indonesia.

**Studio products**

- [Mirae Invoice](https://invoice.miraestudio.id/?utm_source=github&utm_medium=profile): free invoice maker for freelancers, in IDR or SGD.
- [SecScan PQC](https://sec-scan.miraestudio.id/en?utm_source=github&utm_medium=profile): checks whether your servers are ready for post-quantum cryptography. Access by request.

**Open source**

- [ship-pr](https://github.com/Nael-Nathanael/ship-pr): agent skill that takes a task to an open pull request with tests and screenshots.
- [onetake-videogen](https://github.com/Nael-Nathanael/onetake-videogen): local video editing on your GPU, with auto cuts, captions, music and voice-over.
- [secscan-pqc](https://github.com/Nael-Nathanael/secscan-pqc): the scanner behind SecScan PQC. Checks ML-KEM, certificates, TLS and SSH, and writes a PDF report.
- [plasma-liquid-glass](https://github.com/Nael-Nathanael/plasma-liquid-glass): iOS-style liquid glass top bar for KDE Plasma 6.
- [facewatch](https://github.com/Nael-Nathanael/facewatch): one Python file that keeps the screen awake while you look at it and warns you when someone peeks.
- [ccd](https://github.com/Nael-Nathanael/ccd): a single bash file that runs several Claude Code accounts on one machine.
